# Проверка времени на кадрах камер

Камеры наносят дату и время прямо на изображение. Если часы камеры сбились, запись сложнее сопоставить с другими событиями. Проект распознаёт время на кадре, сравнивает его с эталоном и сохраняет результат проверки в CSV.

Репозиторий показывает обработку ошибок распознавания, повторную проверку сложных кадров и сравнение времени с учётом часового пояса.

## Как устроена проверка

1. Входной CSV содержит путь к кадру, эталонное время, часовой пояс и предполагаемое положение надписи.
2. `src/run_easyocr.py` ищет надпись в нескольких областях кадра и распознаёт её с помощью EasyOCR.
3. `src/postprocess_timestamp_results.py` исправляет распознанные строки и пересчитывает разницу с эталоном.
4. `src/rerun_failed_easyocr.py` повторно обрабатывает кадры, которые не удалось уверенно проверить.
5. `src/make_ocr_ensemble.py` выбирает лучший результат для каждого кадра. Итоговый файл: `results/ensemble_result.csv`.

Статус `OK` означает совпадение с эталоном в пределах допуска. `TIMEZONE_MISMATCH` указывает на вероятный сдвиг часового пояса. `TIME_WRONG` означает расхождение, а `NEED_REVIEW` требует ручной проверки. Технические ошибки записываются отдельными статусами. Допуск по умолчанию составляет 10 минут.

## Запуск

Нужен Python 3.10–3.12. При первой настройке загружаются общедоступные веса EasyOCR. Видеокарта не обязательна.

Windows:

```powershell
.\RUN_PIPELINE.ps1 -ImagesDir "D:\camera_frames" -Manifest "D:\manifest.csv"
```

Linux:

```bash
./RUN_PIPELINE.sh --images-dir /data/camera_frames --manifest /data/manifest.csv
```

Пример входного CSV из `config/manifest_template.csv`:

```csv
selected_image_path,reference_time,timezone,camera_id,timestamp_candidate_position
frame001.jpg,2026-06-08T14:31:22+05:00,Asia/Yekaterinburg,cam001,top-right
```

При наличии собственных весов детектор области времени подключается через `--yolo-model` при ручном запуске `run_pipeline.py`. Без них используются ожидаемые области кадра.

Тесты логики без моделей и кадров:

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

В репозитории нет кадров, рабочих манифестов, результатов проверок и собственных весов моделей. Для проверки качества на новых камерах нужны их кадры и эталонное время.
